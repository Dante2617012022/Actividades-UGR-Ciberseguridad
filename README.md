# Actividades UGR - Tecnicatura Universitaria en Ciberseguridad

Repositorio académico de **Dante Gabriel Balbuena Atar** con trabajos realizados durante la Tecnicatura Universitaria en Ciberseguridad de la Universidad del Gran Rosario.

El contenido reúne análisis, laboratorios y documentación sobre seguridad ofensiva y defensiva, gestión de riesgos, continuidad, gobierno, desarrollo seguro, identidad, cloud y entornos OT. Las actividades se presentan como **formación académica y práctica en entornos autorizados**, no como experiencia profesional sobre sistemas de terceros.

## Perfil técnico que demuestra el repositorio

- Reconocimiento, enumeración y análisis de vulnerabilidades.
- Pentesting web en aplicaciones intencionalmente vulnerables.
- Explotación y post-explotación controlada sobre Linux y contenedores.
- Análisis de impacto y recomendaciones de remediación.
- Seguridad de APIs y desarrollo seguro alineado con OWASP.
- Criptografía aplicada, PKI, certificados y firma digital.
- Gestión de riesgos, auditoría, SGSI y continuidad del negocio.
- Seguridad cloud e infraestructuras críticas IT/OT.
- Documentación técnica, ejecutiva y trazabilidad de evidencias.

## Cómo interpretar el material ofensivo

Los informes completos conservan el contexto académico original. Para evaluación profesional se recomienda comenzar por los resúmenes curados, que describen:

- objetivo y alcance;
- metodología aplicada;
- cadena de ataque a alto nivel;
- hallazgos e impacto;
- controles recomendados;
- limitaciones del laboratorio.

No se publican aquí credenciales activas, secretos, datos personales ni autorización para probar técnicas contra sistemas ajenos.

## Alcance ético

Todas las pruebas ofensivas se realizaron en CTF, máquinas intencionalmente vulnerables, contenedores locales o laboratorios provistos con fines educativos. El alcance y las reglas de uso están documentados en [ETHICS_AND_SCOPE.md](ETHICS_AND_SCOPE.md).
