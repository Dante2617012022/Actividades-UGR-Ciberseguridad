# Política de seguridad

## Alcance

Este repositorio contiene documentación académica, informes, capturas y materiales de laboratorio. No aloja un servicio productivo, pero puede existir riesgo de publicación accidental de información sensible.

## Reporte responsable

Si encontrás alguno de los siguientes elementos, evitá abrir un issue público:

- credenciales, tokens, cookies o claves;
- datos personales o información de terceros;
- enlaces privados de clases o reuniones;
- direcciones o nombres internos no sanitizados;
- archivos de configuración con secretos;
- material que exceda el alcance ético declarado.

Reportalo de forma privada al autor indicando:

- archivo y ruta;
- descripción breve;
- evidencia mínima sin volver a difundir el dato;
- recomendación de eliminación o redacción.

## Respuesta prevista

1. Validar el reporte.
2. Retirar o sanitizar el contenido.
3. Rotar credenciales si fueran reales.
4. Revisar historial de Git cuando corresponda.
5. Documentar la corrección sin exponer nuevamente el dato.

## Uso del contenido

La documentación ofensiva es exclusivamente educativa. No autoriza pruebas contra activos ajenos ni actividades fuera de un alcance expresamente permitido.
